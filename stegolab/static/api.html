Local file analysis

Submit multipart evidence with a mode of quick or deep. The response contains the job ID. Poll its status before requesting a report.

curl -F 'file=@challenge.png' -F 'mode=deep' http://localhost:8080/api/jobs
curl http://localhost:8080/api/jobs/JOB_ID
curl http://localhost:8080/api/jobs/JOB_ID/report
curl -X POST http://localhost:8080/api/jobs/JOB_ID/cancel

Endpoints

GET    /api/health                            Worker heartbeat and limits
GET    /api/tools                             Tool registry
POST   /api/jobs                              Multipart: file, mode
GET    /api/jobs?limit=100&offset=0             Job history
GET    /api/jobs/{id}                          Job status and progress
POST   /api/jobs/{id}/cancel                   Request cancellation
DELETE /api/jobs/{id}                          Delete a terminal job and evidence
GET    /api/jobs/{id}/report                   Structured report (?download=1)
GET    /api/jobs/{id}/artifacts/{artifact_id}  Opaque artifact attachment
GET    /api/jobs/{id}/bytes                  Paged bytes (?offset=0&length=512&artifact_id=...)
GET    /api/jobs/{id}/preview/{artifact_id}   Sanitized generated image or audio preview
POST   /api/jobs/{id}/actions                Queue a bounded lab action
GET    /api/jobs/{id}/report?format=markdown&download=true   Markdown export
GET    /api/flags?query=&classification=all&limit=50&offset=0   Indexed candidate search
GET    /api/recipes/operations               Supported byte transformations
POST   /api/recipes                          Queue a transformation chain
POST   /api/utilities                         JSON: operation, text, optional key

Lab actions and recipes

POST /api/jobs/{id}/actions
{"operation":"image_lsb","channels":"RGB","bits":[0],"bit_order":"msb","direction":"row","max_bytes":65536}

Actions: inspect, image_prepare, image_lsb, audio_analyze, flag_scan,
tool_extract, pdf_extract. Optional artifact_id selects an extracted file.

POST /api/recipes
{"input":"ZmxhZ3tsb2NhbH0=","input_encoding":"utf8","steps":[{"operation":"base64_decode"}]}

Recipe input: at most 64 KiB; at most 20 steps; intermediate output budget 4 MiB.
Use GET /api/recipes/operations for the available operation names.

Utilities

{"operation":"base64_decode","text":"ZmxhZ3tsb2NhbH0="}

Operations: base64_encode, base64_decode, hex_encode, hex_decode,
rot13, url_encode, url_decode, hashes, xor

XOR key: hexadecimal bytes; UTF-8 text input; hexadecimal result.
Utility input: at most 64 KiB of UTF-8 bytes.

See the local OpenAPI schema for request types and response codes. Cross-origin browser writes are rejected. All processing remains local.
